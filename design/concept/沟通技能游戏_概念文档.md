# 沟通技能游戏 · 概念文档（Concept）

> 阶段：Phase 1 · 概念（非 GDD）
> 评审强度：Lean
> 形态：情景抉择（Scenario Choice）类沟通技能学习游戏
> 引擎基线：Godot ｜ 平台：iOS / Android 移动端（竖屏优先）
> 素材来源：《沟通的艺术》技能蒸馏版，共 34 个技能，分 6 大篇
> 文档 owner：design-strategist（文策渊）｜ 状态：已定稿（支柱 P1/P3/P4，待 Phase 2）

## 0. 一句话定位

**一款让玩家在安全的虚拟对话里"先犯错、再看懂为什么"的沟通训练游戏**——把卡耐基 34 个技能的「识别触发 → 抉择技巧 → 看后果 → 复盘/再练」闭环，做成竖屏、3 分钟一局的情景抉择循环。

---

## 1. MDA 框架拆解

### 1.1 Mechanics（机制：规则、程序、系统构件）

| 机制 | 说明 |
|---|---|
| **情景容器** | 每个场景 = 一个真实沟通处境（IM 对话 / 会议 / 家庭餐桌等），呈现：情境背景、对方最后一句（或动作）、「你的冲动」（内心独白，暴露本能反应）、该 NPC 的「关系账户」基线（注：关系账户为扩展层系统，MVP 单局无 meter）。 |
| **触发识别（Diagnose）** | 玩家在选回应前，先给处境打「类型标签」（如「对方在防御 / 我正想批评」「对方需要被看见」「纯事务沟通」）。正确识别才解锁对应技能选项，并单独计分。 |
| **抉择分支（Choose）** | 每个处境 2–4 个回应选项，写成「你实际会说的话」，而非技能标签。通常含：1 个熟练路径（对应技能的 E 步骤）、1–2 个常见陷阱（书中失败模式 / 语言信号，如「把证据摆全让他认错」）、偶尔 1 个「边界」路径（该技能本不该用的情境，如安全红线）。 |
| **后果引擎（Consequence）** | 每个选择映射一段短模拟：对方反应（台词 / 微表情）、一句后果判词（关系账户增减为扩展层系统，MVP 单局无数值 meter）。陷阱选择展示**反噬**（防御、记恨、等待成本），而非说教。 |
| **复盘面板（Review）** | 抉择后展开：机制原理解释（I 段，讲 WHY）、真实历史案例佐证（A1 段）。（按用户决策不纳入 P2，复盘不含额外伦理/边界批注，保持轻爽。） |
| **再练 / 推进（Replay）** | 「再练一次」（同场景换选择）与「下一场景」；按技能记录掌握度。 |

### 1.2 Dynamics（动态：机制涌现出的实际玩法）

- **「先诊断再选」成为习惯**：因为不识别就无法解锁正确选项，玩家被结构性地逼着在开口前停一下——这正是书里最难的一条习惯。
- **陷阱选项是老师**：诱惑性选项精准对应玩家的真实本能（摆证据、等对方认错），选了并看到反噬，比任何讲解都记得住——负反馈即教学。
- **关系账户形成回路（扩展层）**：反复正确选择积累可见的「关系存款」，玩家对 NPC 产生「我在好好对待这段关系」的体感（MVP 暂不以数值呈现，靠后果与复盘承载）。
- **间隔重复**：同一技能多个变体场景 + 跨场景复现，强化迁移。
- **诚实可见**：后果如实展示对方反应与关系走向，让玩家自行体会话术得失，不额外弹伦理批注（按用户决策移除 P2，保持轻爽）。

### 1.3 Aesthetics（美学：玩家应获得的情感体验）

| 美学目标 | 体验描述 |
|---|---|
| **Insight（顿悟）** | 「原来如此」——机制点亮的瞬间。 |
| **Safe Failure（安全失败）** | 在虚拟里把社交雷踩一遍，零真实代价。 |
| **Self-Efficacy（自我效能）** | 「这种对话我现在真能接住了。」 |
| **Wry Recognition（会心自嘲）** | 看到陷阱选项时「这不就是我吗」的一笑。 |
| **Calm（平静）** | 像不带评判、却在关键时刻点醒你的朋友，而非讲师。 |

> Bartle 玩家类型对齐：本作以 **Achiever（掌握度 / 完成 / 精通）** 与 **Explorer（读案例、挖机制）** 为主，无 PvP 社交层。美学设计优先服务这两类。

## 2. 游戏支柱（设计北极星，3 条 · 已定稿）

> 以下 3 条（已定稿）决定后续所有取舍。原 P2「真实且有边界」经用户决策不纳入，以保持轻爽。

**P1 · 后果可见，不说教（Show, don't preach）**
一切技能通过「模拟后果」教会，而非「你应该」。复盘用真实案例佐证，不用训诫口吻。

**P3 · 识别优先于技巧（Diagnose before you choose）**
核心闭环把「触发识别」作为第一、也最难的一步；没有诊断的选项再漂亮也是盲选。这是与同类「选择题」游戏最大的差异点。

**P4 · 低门槛、高频、可重玩（Low-friction, replayable）**
移动端竖屏、单局 3 分钟内、场景即卡片、随时重练。用「频率」本身复刻书里 s31 / s33 的微观信号理念（meta 层一致）。

## 3. 核心学习循环设计

### 3.1 循环总览（四拍 + 再练）

```
[进入场景] → [① 识别触发] → [② 抉择技巧] → [③ 看后果] → [④ 复盘/再练]
                Tag the trigger   Pick a response   See consequence   Review + Replay
```

### 3.2 每拍细节（玩家动作 / 系统职责 / 防说教设计）

**Beat 0 · 进入场景**
- 玩家：读处境、看对方、看到自己「冲动」气泡。
- 系统：渲染场景卡片，展示 NPC 关系账户基线。
- 防说教：用「冲动气泡」让玩家自己认出本能，而非系统替他定罪。

**Beat 1 · ① 识别触发（对应 A2）**
- 玩家：从 2–4 个候选标签里给处境定性。
- 系统：判对错 → 解锁对应技能选项；错误识别导致选项错位、后果反噬，自然纠错。
- 防说教：识别本身就是「学」，不另开讲解页。

**Beat 2 · ② 抉择技巧（对应 E）**
- 玩家：选一句真实会说的话。
- 系统：陷阱选项故意诱人（贴合书里的「语言信号」）；边界选项对应不该用的情境。
- 防说教：选项不写「正确/错误」标签，结果自己说话。

**Beat 3 · ③ 看后果（对应 A1 的结果逻辑）**
- 玩家：看 NPC 反应 + 后果判词（MVP 无数值 meter，反馈靠后果与复盘承载）。
- 系统：短模拟 + 一瞥长期代价（如 s01 的「等待必败」、s02 的「坐标错位」）。（MVP 无 P2 边界提示，后果自己说话。）
- 防说教：展示「发生了什么」，不评价「你错了」。

**Beat 4 · ④ 复盘 / 再练（对应 I + A1）**
- 玩家：读机制 / 看案例；选择「再练一次」或「下一场景」。
- 系统：复盘面板 = 机制（WHY）+ 真实案例（证据，用「X 身上发生过」而非「你必须」）。按技能记掌握度。
- 防说教：证据用历史案例承载可信度；复盘给玩家迁移线索，而非被动接受「永远该用」。

### 3.3 自我决定论（SDT）三需求映射

| 需求 | 在循环里如何被满足 |
|---|---|
| **自主 Autonomy** | 玩家自选场景 / 技能、自选选项、随时重练；游戏从不强制单一「正确道德」，只展示后果。 |
| **胜任 Competence** | 复盘讲清 WHY 使能力增长；按技能掌握度可见（关系账户数值反馈为扩展层系统，MVP 以复盘为主）。 |
| **关联 Relatedness** | 场景本质是「与人相处」；玩家间接「好好对待」NPC；扩展层将以关系账户作为关联的代理指标。 |

### 3.4 避免说教的四道保险

1. **后果驱动**：永远 show 不 tell，NPC 反应是老师。
2. **陷阱即教学**：诱人选本能错招，反噬自身即教训。
3. **案例作证**：复盘用真实历史案例（A1），框为「X 的经历」而非规训。
4. ~~边界入内容~~ **（已按用户决策移除）**：原拟把书自身的伦理批判（s05 质量门、操纵反对意见）做成正式内容；用户决策不纳入 P2、保持轻爽，故仅以后果 + 案例承载，不作正式支柱、不弹额外批注。

## 4. 范围分层（Lean 节奏）

> 依赖顺序依据蒸馏稿的 Zettelkasten `depends-on`：第 1 篇内部自洽（多为空依赖或在篇内），第 3 篇 s14 依赖 s13、s17 依赖 s10/s13，第 4 篇普遍依赖 s03/s04——故「1 → 2/3 → 4/5/6」既是内容顺序也是教学顺序。

### 4.1 三层对照表

| 层 | 覆盖技能 | 系统深度 | 目标 / 验证假设 | Lean 优先级 |
|---|---|---|---|---|
| **MVP（Layer 1）** | **第 1 篇 s01–s06**（6 技能：不批评 / 理解替代批评 / 显要感 / 真诚赞赏 / 赞赏vs恭维 / 鱼饵理论） | 场景引擎、选项-后果静态表、触发识别 tag、复盘面板、按篇技能地图（关系账户 meter 推迟到扩展层，本层单局无 meter） | 验证「好玩且能学到」+ 核心循环 + SDT 三需求；形成完整 mini-arc（含 1 条禁令、1 条供给） | **最高** |
| **扩展层（Layer 2）** | 第 2 篇 s07–s12（6）+ 第 3 篇 s13–s24（12）= 18 技能 | 关系/信任纵向追踪（跨场景同 NPC，含关系账户 meter）、分支场景树（选项级联）、案例库浏览、自由练习模式、难度梯度、间隔复习提醒 | 覆盖主体内容，建立长期留存 | 中 |
| **远期层（Layer 3）** | 第 4 篇 s25–s30（6）+ 第 5 篇 s31–s33（3）+ 第 6 篇 s34（1）= 10 技能（更微妙：改变他人不冒犯 / 家庭长期 / 信函） | 跨技能组合场景（用 `composes-with` 图串联多技能）、程序化场景生成（模板+变量）、用户自建场景、本地化、教练/反思日记 meta 叙事；可考虑「对手反应 AI」让 NPC 对前后选择连贯反应（仍单玩家） | 完整知识图谱 + 高阶迁移 | 低 |

### 4.2 Lean 节奏说明

- **MVP 不贪多**：6 技能已足以验证最贵的假设（核心循环是否好玩+能学）。第 1 篇天然是全书形状的微缩（禁令+供给俱全），自洽可独立发行。
- **先确认再铺量**：MVP 数据（完成率、复盘阅读率、重练率）达标后，再启动扩展层；避免在未验证循环前堆 34 技能内容。
- **每个技能内容配方（MVP）**：3–4 个脚本场景 = 覆盖不同触发变体 + ≥1 陷阱场景 + ≥1 边界场景。

## 5. 视觉锚点（给美术，仅定调不代工）

> 以下为**锚点与情绪基调**，供 art-director 解读，非美术指令。具体风格由美术定。

**关键词（3–5）**
1. **日常对话感**：聊天气泡、竖屏 IM 式呈现，像真实聊天而非课堂。
2. **克制留白**：负空间、平静构图——呼应「不打翻蜂巢」的不打扰哲学。
3. **微表情 / 人物剪影**：用细微表情与姿态变化传递对方反应，而非大特效轰炸。
4. **暖中性色**：warm neutrals，无攻击性、无说教式高饱和。
5. **卡片化轻量**：场景=卡片，便于移动端 3 分钟一局。

**情绪基调**
**平静而有回响（calm but resonant）**——一个不带评判、却在关键时刻点醒你的朋友；安全、可失败、事后会心一笑的温暖。
*避免*：说教式励志高饱和感；职场 PPT 冷感。

## 6. 垂直切片建议（Vertical Slice）

> 已决：首个可玩切片 = **s01（不批评 / 打翻蜂巢）+ s03（显要感 / 自重感）**，可选加 s04（真诚赞赏）测试「供给侧生成」交互。

**为何 s01 适合**
- 触发极清晰（你正要批评 / 对方在防御），且陷阱选项「把证据摆全让他认错」**正是玩家真实本能**——天然验证「陷阱即教学」。
- 后果是**负收益而非中性**（防御→记恨→等待必败），反直觉且易戏剧化，最契合 P1「show don't preach」。
- 含「边界」情境（安全/合规红线、被批评方在 PUA），可验证 P3 识别优先与陷阱/边界的区分。

**为何 s03 适合**
- 它是全书**动机地基**（解释 s01 为何奏效，并 `composes-with` s04/s18/s34/s27），验证 P3「识别优先」支柱。
- 自带「诊断 vs 操作」双子循环，可测两种不同交互（诊断落点 / 设计具名供给）。
- 教给玩家的是**可迁移心智模型**，而非单招，学习价值最高。

**两者组合的价值**
- s01（一条「别做 X」的禁令场景）+ s03（一条「去做 Y」的供给场景）= 覆盖基本技巧篇的两种极性，能把「识别→抉择→后果→复盘」完整跑两遍、且相互抵消盲区。
- s05 质量门等伦理内容按用户决策不纳入 P2 正式支柱，必要时应延后到扩展层；本切片保持轻爽。

**备选 / 补充**
- 若想要「生成一句话」的更强交互，可把 s03 换成 **s04（真诚赞赏）**——其「锁定最小真实单元 / 颗粒度倒置」有最具体的句子级操作，交互更实。推荐：**切片 = s01 + s03（+ 可选 s04 作为第三个场景以测试「供给侧生成」交互）**。

3. **MVP 范围（已决：第 1 篇全 s01–s06）**：MVP 覆盖第 1 篇全部 6 技能，形成完整 mini-arc。
4. **关系账户 meter（已决：推迟到扩展层）**：MVP 单局无 meter，反馈靠后果与复盘承载；关系账户系统延至扩展层。
5. **美术基调（已决，由 art-director 落地）**：暖中性克制方向已由 art-director 按第 5 节锚点落地，无需再选。

## 8. 已知风险与取舍

- **声誉风险（残余，已接受）**：只 show 后果不 show 边界，可能被批「教人操纵」；用户决策有意保持轻爽、不纳入 P2，故接受该残余声誉风险，仅以后果 + 案例承载可信度，不弹额外伦理批注。
- **说教风险**：若复盘写成「你应该」→ 用「后果驱动 + 案例证据」两道保险对冲（原第 4 道「边界入内容」已按决策移除）。
- **文化适配成本**：34 技能案例多为 1930s 美国语境，需本地化改写（隐性内容生产成本）。
- **陷阱太明显**：若错招一眼假，玩家「猜对」而非「学到」→ 需真实诱惑性，依赖文案功力。
- **UX 早对齐**：竖屏对话呈现依赖美术/工程在 UX 上早介入（Phase 2 我会出首个切片 UX 规格，本阶段仅概念）。
