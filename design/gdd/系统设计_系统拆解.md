## 2. 各系统规格（Lean）

### S1 · 内容数据层
- **职责**：以结构化数据（见 `内容数据schema.md`）描述每个场景的全部可玩内容；与表现层解耦，支持后续扩充 34 技能无需改代码。
- **输入**：策划/文案填表（JSON/YAML）。
- **输出**：场景实例数据结构。
- **依赖**：无（L0 地基）。
- **MVP 范围**：s01–s06 共 6 技能 × 3–4 场景。
- **验收**：任一场景可由纯数据驱动渲染，无需硬编码分支。

### S2 · 场景引擎
- **职责**：读取场景数据，渲染场景卡（情境背景、对方最后一句/动作、玩家「冲动」气泡）。
- **输入**：场景实例。
- **输出**：可视场景卡 + 进入 S3。
- **依赖**：S1。
- **验收**：竖屏单屏可完整呈现，3 分钟内可进入抉择。

### S3 · 触发识别系统（P3 支柱承载）
- **职责**：呈现 2–4 个候选标签，校验玩家选择；**识别正确才解锁对应技能选项**，识别错误则选项错位、后果自然反噬。
- **输入**：场景的 `triggers.candidates` 与 `triggers.correct`。
- **输出**：识别结果（对/错）+ 解锁的选项集。
- **依赖**：S2。
- **验收**：未识别即无法进入有效抉择；识别错会触发可感知的「错位」后果（自学）。

### S4 · 抉择系统
- **职责**：渲染 2–4 个回应选项（熟练/陷阱/边界），捕获选择并透传类型。
- **输入**：解锁的选项集（含 `type`）。
- **输出**：玩家选择 + 选项类型。
- **依赖**：S3。
- **验收**：选项写成「真实会说的话」而非技能标签；陷阱选项具备真实诱惑性。

### S5 · 后果引擎
- **职责**：按选择查表，输出对方反应 + 后果判词（+ 展示用关系信号，不持久化）。
- **输入**：选择 + 选项类型 + 对应 `consequence`。
- **输出**：后果演出（台词/微表情/判词）。
- **依赖**：S1（consequence 数据）、S4。
- **验收**：陷阱选择展示反噬、熟练选择展示关系软化；MVP 为静态映射，无随机性。

### S6 · 复盘系统
- **职责**：展开机制（WHY）+ 真实案例（证据）+ 迁移线索；提供「再练一次 / 下一场景」。
- **输入**：场景的 `review` 数据 + 本次选择。
- **输出**：复盘面板 + 导航。
- **依赖**：S5。
- **验收**：用「X 身上发生过」而非「你必须」；不含额外伦理批注（P2 已移除）；文本克制不超载。

### S7 · 掌握度系统
- **职责**：按技能记录轻量掌握度（场景完成数、复盘是否阅读、是否重练）。
- **输入**：S4/S6 事件。
- **输出**：技能掌握度（如 0–3 档）。
- **依赖**：S4、S6。
- **MVP 验收**：不弹分数压力；仅作技能地图的小标记。

### S8 · 技能地图/导航
- **职责**：按篇（第 1 篇）呈现技能入口与场景列表。
- **输入**：S1 元数据。
- **输出**：导航。
- **依赖**：S1。
- **MVP 验收**：竖屏可达，切片阶段 s01 / s03 / s04 三个入口。

### S9 · 关系账户（推迟）
- 扩展层实现；本层仅在 Schema 预留 `relationshipSignal`（展示用，不持久化）。

## 3. 依赖排序与构建顺序

```
L0   S1 内容数据层
          │
L1   S2 场景引擎        S8 技能地图（元数据即可）
          │
L2   S3 触发识别        S4 抉择系统
          │                │
L3        └──── S5 后果引擎
                    │
L4          S6 复盘系统      S7 掌握度系统
```

**推荐构建顺序**：S1 → S2 →（S3 + S4）→ S5 → S6 →（S7 + S8）。
垂直切片最小闭环 = **S1(5 场景) + S2 + S3 + S4 + S5 + S6**；S7/S8 切片期可最简，MVP 完整化。

**依赖约束（给工程）**
- S3 必须作为 S4 的硬闸门：选项集由识别结果派生，不允许「跳过识别直接选」。
- S5 后果为**静态查表**（MVP），不引入随机/AI，保证 Lean 与可评审。
- S1 数据结构是全局单一事实源；所有 S2–S8 只消费 S1 数据，禁止在代码里写死场景文案。

## 4. 与概念文档的对齐

- **P1 后果可见不说教** → S5（后果自己说话）+ S6（案例佐证）。
- **P3 识别优先于技巧** → S3（硬闸门）。
- **P4 低门槛高频可重玩** → S2 单屏 + S6「再练一次」+ S7/S8 轻量导航。
- **P2 已移除** → S6 不含伦理批注；S1 数据无 `ethicsGate` 字段（扩展层才加）。
- **关系账户推迟** → S9 不在 MVP；S5 的 `relationshipSignal` 仅展示不持久化。
