## 2. 去 P2 后「三道保险」自洽性

原四道保险：① 后果驱动 ② 陷阱即教学 ③ 案例作证 ④ 边界入内容（=P2）。
P2 移除后剩 ①②③。

| 保险 | 载体 | 是否仍自洽 |
|---|---|---|
| ① 后果驱动 | S5 后果引擎（NPC 反应说话） | ✅ 不依赖 P2，独立成立 |
| ② 陷阱即教学 | S4 选项设计（真实诱惑陷阱）+ S5 反噬 | ✅ 不依赖 P2，独立成立 |
| ③ 案例作证 | S6 复盘（`review.case`） | ✅ 不依赖 P2，独立成立 |

**结论**：①②③ 均为机制/内容层能力，与 P2（伦理批注层）正交；移除 P2 不影响其运作。「不说教」目标由 ①②③ 完整承载，自洽。

**残余风险（已在概念 §8 标注「已接受」）**：仅 show 后果不 show 边界，可能被批「教人操纵」。此为有意取舍（保持轻爽），非一致性缺陷。

## 3. 设计理论红线（SDT / 主导策略 / 经济 / 认知 / 支柱漂移）

### 3.1 主导策略（Dominant Strategy）
- **风险**：若每场景都「skilled = 唯一正确、trap = 必错」，游戏退化为「找正确答案」的测验，失去学习感。
- **自检**：本作**非对抗性单人游戏**，无传统 balance 意义上的主导策略；但需防「背答案」。缓解：① 陷阱选项写实、诱惑性强（S4 文案要求）；② 后果由体验而非评分给出（S5/S6 不弹对/错分）；③ 边界场景（E2）证明「熟练路径并非万能」。→ **未越红线**，但需在文案评审盯紧「陷阱真实性」。

### 3.2 经济失衡（Economy Imbalance）
- **自检**：MVP **无资源经济**（关系账户推迟、无货币/点数交易）。`relationshipSignal` 仅展示不累积。→ **不适用**，无失衡风险。扩展层引入 S9 时需重检。

### 3.3 认知过载（Cognitive Overload）
- **自检**：单屏单局、选项 2–4、识别标签 2–4、复盘三段短文本；竖屏 3 分钟。→ **未越红线**。
- **开放警示**：S6 复盘文本需克制（机制/案例/迁移各 1–2 句），避免 Phase 3 文案膨胀导致过载；列为验收隐性项。

### 3.4 支柱漂移（Pillar Drift）
逐系统映射：
- P1 后果可见不说教 → S5 + S6 ✅
- P3 识别优先于技巧 → S3 硬闸门 ✅
- P4 低门槛高频可重玩 → S2 单屏 + S6 再练 + S7/S8 轻导航 ✅
- 无系统服务于已移除的 P2 ✅

→ **无漂移**，三支柱均有系统承载。
